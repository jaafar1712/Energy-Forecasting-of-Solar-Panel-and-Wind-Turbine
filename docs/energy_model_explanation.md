# Hybrid Solar/Wind Digital Twin and AI Forecasting

## Project Goal
This project creates a synthetic digital-twin dataset for a hybrid Solar/Wind system in Annecy, France, then trains machine-learning models for power prediction and short-term forecasting.

## What the Pipeline Produces
1. Synthetic dataset with 1 year of hourly samples (8760 rows)
2. Static plots for quick sanity checks
3. Optional live animated dashboard plots
4. Baseline Random Forest model for same-timestamp power prediction
5. Random Forest model for 1-hour-ahead power forecasting
6. Saved model artifacts for reuse and deployment

## Data Generation Logic
### Inputs (Features)
- timestamp: hourly datetime index
- lux_sensor: diurnal sine wave plus seasonal modulation and cloud noise, clipped to 0-120000 lux
- wind_speed_ms: Weibull-distributed wind speed, clipped to 0-25 m/s
- wind_direction_deg: uniformly sampled in 0-360 degrees
- ambient_temp_c: seasonal and daily cycles plus correlation with lux and random noise, clipped to -5 to 35 C

### Outputs (Targets)
- power_produced_w: sum of synthetic solar and wind power components
- current_produced_a: computed from I = P / V
- voltage_v: around 24V with bounded noise

### Physics-Inspired Equations
- Solar term is proportional to light level:
  P_solar = P_rated * (lux / lux_max)
- Wind term scales approximately with cube of speed:
  P_wind = k * v^3
- Total power:
  P_total = P_solar + P_wind
- Current:
  I = P / V

## Model Training
### Baseline Model
- Algorithm: RandomForestRegressor
- Task: predict current-hour power_produced_w
- Split: random 80/20 train-test
- Metrics: MAE and R2

### Forecast Model
- Algorithm: RandomForestRegressor
- Task: predict next-hour power (power_next_1h_w)
- Target shift: power_produced_w shifted by -1 hour
- Split: chronological 80/20 (time-aware)
- Metrics: Forecast MAE and Forecast R2

## Interpreting the Metrics
- MAE (W): average absolute prediction error in watts
- R2: variance explained by the model
  - 1.0 is perfect
  - 0.0 equals mean baseline
  - negative means worse than mean baseline

For hourly data, a forecast MAE in watts is approximately equivalent to Wh error per hour interval.

2. Run the script:

3. Optional no-GUI mode:
   .\.venv\Scripts\python.exe .\train_energy_model.py --no-live-plots
